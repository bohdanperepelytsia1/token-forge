# Кузня токенів

Веб-додаток для НРІ: прибирає фон з арту персонажа й робить токени для VTT (Foundry, Roll20, Owlbear тощо).
Усе працює в браузері користувача. Зображення не завантажуються на сервер, бо сервера з обробкою тут немає: сайт повністю статичний.

## Можливості

- **Прибрати фон**: нейромережа ISNet (через `@imgly/background-removal` і ONNX Runtime). Маска потім уточнюється керованим фільтром, а з напівпрозорих країв прибирається відтінок старого фону. Для ручного доведення є паличка, гумка, пензель відновлення, прибирання ореолу, згладжування й історія дій.
- **Окрема вкладка «Прибрати фон»**: зберігає PNG із прозорим, білим або будь-яким кольоровим тлом і за бажанням обрізає порожні краї.
- **Токени**: 6 форм, 28 стилів рамок, 35 готових рамок і 24 тла (16 процедурних текстур). Є ефект «голова за рамкою», стрічка з ім'ям, значок із номером і тінь.
- **Експорт**: PNG або WebP від 256 до 2048 px, ZIP-пакет пронумерованих токенів і окремий шар персонажа для Foundry Dynamic Token Ring.
- **Завантаження**: файл, перетягування, Ctrl+V, а також посилання на картинку чи на сторінку з нею (Pinterest, ArtStation, DeviantArt, Reddit, Imgur, Google Картинки).

## Запуск

Потрібен Node.js 20+.

```bash
npm ci
npm run build      # збирає dist/ (~165 МБ, переважно AI-моделі)
npm start          # http://127.0.0.1:8080
```

Відкривати треба через сервер, а не подвійним кліком по файлу: AI потребує заголовків COOP/COEP (багатопотоковість) і доступу до папки `models/`.

## Розгортання

### Варіант 1. Cloudflare Pages (найпростіше, безкоштовно)
1. Підключіть репозиторій у Cloudflare Pages.
2. Команда збірки: `npm run build`, папка: `dist`.
3. Заголовки безпеки підхоплюються автоматично з `dist/_headers`. Файли моделей нарізані шматками по 4 МБ, тож ліміт Pages (25 МБ на файл) не заважає.

### Варіант 2. Свій сервер (поруч із G.O.D.)
```bash
sudo git clone <repo> /opt/token-forge && cd /opt/token-forge
sudo npm ci && sudo npm run build
sudo cp deploy/token-forge.service /etc/systemd/system/
sudo systemctl enable --now token-forge     # слухає 127.0.0.1:8090
```
Далі спрямуйте Cloudflare Tunnel або nginx на `http://127.0.0.1:8090`. Вбудований сервер `scripts/serve.mjs` сам віддає всі заголовки безпеки.

### Варіант 3. Docker
```bash
docker build -t token-forge .
docker run -d --name token-forge -p 127.0.0.1:8090:8080 --read-only --tmpfs /tmp --cap-drop ALL token-forge
```

### Свій проксі для посилань (рекомендовано для публічного сайту)
За замовчуванням картинки за посиланням тягнуться через публічні сервіси `wsrv.nl`, `allorigins.win` і `corsproxy.io`. Для публічного сайту краще мати свій проксі:
1. `cd deploy/proxy-worker`, у `wrangler.toml` вкажіть адресу свого сайту в `ALLOWED_ORIGINS`.
2. `npx wrangler deploy`.
3. У `dist/config.js` (або `src/config.js` перед збіркою) вкажіть `proxy: 'https://token-forge-proxy.<ваш>.workers.dev'`.
4. Додайте адресу проксі в `connect-src`: змінна середовища `TF_PROXY_ORIGIN` під час збірки або запуску `npm start`, а для nginx — у `deploy/security-headers.inc`.

## AI на відеокарті
Вбудовані моделі (з npm-пакета `@imgly/background-removal-data@1.4.5`) працюють на процесорі в кілька потоків. WebGPU для них не підходить. Щоб рахувати на відеокарті, у `config.js` вкажіть `aiDevice: 'gpu'` і `modelPath: 'https://staticimgly.com/@imgly/background-removal-data/1.7.0/dist/'`, а `https://staticimgly.com` додайте в `connect-src`. Тоді моделі завантажуватимуться з CDN бібліотеки. Цей режим не тестувався в цьому репозиторії.

## Структура
```
src/            код сторінки (app.js, render.js — рамки й тла, loader.js — безпечне завантаження, refine.js — доведення маски)
scripts/        build.mjs (збірка), serve.mjs (сервер), headers.mjs (заголовки безпеки)
deploy/         nginx, systemd, проксі-воркер
public/         статичні файли (іконка)
```
